## 公告可见性（visible）后端支持
- Announcement 实体新增 visible Boolean（nullable=false，默认 true）
- GET /api/v1/announcements 自然带出 visible 字段（实体直接序列化，不过滤 hidden，由前端控制渲染）
- POST /api/v1/announcements 接收可选 visible（缺省 true，向后兼容）
- 新增 PUT /api/v1/announcements/{id}（body {"visible": bool}），不存在返回 404；SecurityConfig 增加 PUT /api/v1/announcements/* 管理员规则
- AnnouncementService.publish 增加 visible 参数、新增 updateVisible(id, visible)；操作日志 action=ANNOUNCEMENT_VISIBLE
- 新增 sql/migration_v5.sql（ALTER TABLE announcement ADD COLUMN IF NOT EXISTS visible BOOLEAN NOT NULL DEFAULT true）
- 注意：build 目录可能被运行中的 devtools/IDE 进程锁文件，gradle 偶发 AccessDenied，重试即可
